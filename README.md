# Nova Tech - Actividad 23

Tienda de accesorios tecnologicos con login (BCRYPT), sesiones en PHP y un endpoint privado (`api/mis_compras.php`).

## Como probarlo

1. Clonar el repo dentro de `C:\xampp\htdocs\`
2. Abrir XAMPP e iniciar Apache y MySQL
3. Entrar a phpMyAdmin, ir a Importar y cargar `sql/nova_tech.sql`
4. Abrir http://localhost/Actividad-23/

Usuario de prueba: `demo@novatech.com` / `demo1234` (o registrarse con uno nuevo)

Si su MySQL tiene contraseña hay que ponerla en `config/conexion.php`.
